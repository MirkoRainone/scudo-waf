Perché scegliere uno Scudo Ibrido In-Memory?

PromptGuard per App AI / LLM

I WAF tradizionali ignorano il linguaggio naturale. Il decoratore @guard.protect e il motore NLP bloccano Prompt Injection e Jailbreak prima che raggiungano il tuo LLM.

Latenza Sub-Millisecondo + Fail-Open

L1 Regex (~0.01ms) e L2 Cache (~0.05ms) filtrano il traffico noto istantaneamente; L3 ML esegue in ~3.3–5.6ms nella tua RAM locale senza chiamate esterne bloccanti.

Monitor Mode & Zero Falsi Positivi

Testa in produzione in modalità monitor prima di attivare il blocco. Modello calibrato con hard-negative (nomi con apostrofi, JSON, indirizzi) e soglia configurabile.

Domande Frequenti (FAQ)

Il modello scikit-learn (TF-IDF + CalibratedLinearSVC) e le firme regex vengono caricati direttamente nella RAM della tua applicazione Python all'avvio. L'ispezione avviene in locale senza attendere API esterne.

FastAPI / Starlette tramite ASGI WafMiddleware, Flask con ScudoFlask(app), Django con ScudoDjangoMiddleware e qualsiasi pipeline LLM con PromptGuard.

Imposta mode="monitor" nel middleware: Scudo rileva e notifica eventuali anomalie tramite il callback on_block o la telemetria asincrona lasciando passare le richieste, ideale per validare zero falsi positivi prima del blocco.
