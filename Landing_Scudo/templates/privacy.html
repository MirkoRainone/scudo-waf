1. Minimizzazione dei Dati & Ispezione In-Memory

Il pacchetto Open-Core scudo-waf esegue l'analisi delle richieste HTTP e dei prompt LLM interamente nella memoria locale (RAM) del server del cliente: nessun dato legittimo viene trasmesso al cloud di Scudo WAF quando la telemetria remota è disabilitata o quando l'input è benigno.

2. PII & Secret Redaction

Quando la funzionalità PII Redactor è attivata sui tenant cloud o su PromptGuard, indirizzi email, numeri di carte di credito (verificati via algoritmo di Luhn), codici IBAN, Codici Fiscali e chiavi API vengono mascherati automaticamente ([REDACTED_*]) prima della registrazione nei log di sicurezza o dell'invio ai modelli LLM.

3. Sicurezza delle Credenziali

Le API Key dei tenant vengono archiviate mediante digest crittografico irreversibile (SHA-256) e non vengono mai conservate in chiaro dopo il provisioning iniziale.

4. Conservazione e Diritti dell'Interessato

Gli eventi di telemetria troncati (massimo 500 caratteri per evento bloccato) e gli indirizzi email utilizzati per la fatturazione sono conservati esclusivamente per l'erogazione del servizio e la sicurezza applicativa. L'utente può richiedere in qualsiasi momento la cancellazione dell'account e dei relativi log direttamente dalla console o via supporto.
