Termini di Servizio (Terms of Service)

Ultimo aggiornamento: Novembre 2026 · Scudo WAF SaaS & Open-Core Platform

1. Oggetto del Servizio

Scudo WAF fornisce un motore ibrido di Web Application Firewall (Open-Core SDK e Proxy Sidecar) e un Control Plane Cloud per analisi, telemetria, gestione policy personalizzate e protezione Prompt Injection / PII Redaction per applicazioni AI.

2. Architettura Fail-Open & Limitazione di Responsabilità SLA

Per garantire la continuità operativa delle API dei clienti, i middleware di ispezione adottano come comportamento predefinito la modalità Fail-Open: in caso di errore imprevisto dell'engine di analisi o irraggiungibilità temporanea della telemetria cloud, le richieste applicative continuano a essere servite. Nessun WAF o sistema di Machine Learning garantisce il rilevamento del 100% delle minacce zero-day; Scudo WAF opera come strumento di difesa in profondità e non sostituisce la validazione applicativa (es. query parametrizzate e controllo accessi).

3. Piani, Quote Mensili e Fatturazione Stripe

Il Piano Free include fino a 10.000 scansioni/mese sul Control Plane Cloud e uso illimitato locale dell'SDK Open-Core. Il Piano Pro (€29/mese) include fino a 500.000 scansioni/mese, regole personalizzabili e webhook alert. L'abbonamento è gestito tramite Stripe Billing e può essere annullato in qualsiasi momento; al termine del periodo pagato l'account torna automaticamente al Piano Free.

4. Uso Accettabile

È vietato utilizzare gli endpoint API pubblici o il Live Playground di Scudo WAF per condurre test di carico non autorizzati, attacchi DoS o scansioni automatizzate verso infrastrutture di terzi.
